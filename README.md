# Fitness Phoenix — site demo

Propunere de site pentru Fitness Phoenix (Str. Mircea Vodă nr. 1, Tecuci). Demo realizat de Manotek.

- Tot conținutul: `content/site.ts` (caută „[de completat]”).
- Formular: setează variabila de repo `FORMSPREE_ID`; fără ea, formularul deschide WhatsApp.
- `npm run dev` / `npm run build` (export static în `out/`). Publicare automată pe GitHub Pages la push pe `main`.
